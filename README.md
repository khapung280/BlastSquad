# BlastSquad 🔫

Fast-paced 6-player multiplayer shooter game on Roblox.

## Game Modes
- 1v1 — First to 10 kills
- 2v2 — First team to 20 kills
- 3v3 — First team to 30 kills
- FFA — Free for all, first to 15 kills
- 2v2v2 — 3 teams, first to 20 kills

## Features
- PC + Mobile friendly
- Mode voting system
- Live HUD with kill feed
- K/D tracking

## Built With
- Roblox Studio
- Luau
- Cursor + Claude Opus 5
